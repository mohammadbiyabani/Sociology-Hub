# Sociology Study Hub & AI Tutor 🎓

A trilingual AI-powered Sociology study hub and exam assistant designed for high school, BA, MA, UGC-NET, and UPSC competitive exam preparation.

🔗 **Live App:** [https://sociology-study-hub-ai-tutor.ai.studio/](https://sociology-study-hub-ai-tutor.ai.studio/)

## ✨ Key Features
* 🌐 **Trilingual AI Tutor:** Instant explanations in English, Hindi (हिंदी), and Telugu (తెలుగు).
* 🤖 **Persistent Assistant:** Chat with the AI continuously while browsing syllabus topics, quizzes, or notes.
* ✍️ **Model Answer Studio:** Generates structured 15/20-mark university essay outlines (Introduction, Theoretical Framework, Indian Context, Conclusion).
* 📚 **Complete Syllabus Coverage:** Organized modules for Classical/Modern Thinkers (Marx, Durkheim, Weber), Research Methodology, and Indian Sociology (Srinivas, Ambedkar, Ghurye).
* 📝 **Textbook Workspace:** Paste raw chapter text or notes to generate key takeaways and revision questions.
* 📱 **PWA Ready:** Works seamlessly on desktop web browsers and smartphones ("Add to Home Screen").

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS
* **AI Integration:** Google Gemini API (`GEMINI_API_KEY`)
* **Platform:** Google AI Studio / Progressive Web App (PWA)
